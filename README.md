# HSV-Segmentation# 🍎 Fruit & Vegetable Ripeness Classification System

> Automated fruit and vegetable categorization and ripeness detection pipeline using Classic Computer Vision techniques and Machine Learning.

---

## 📋 О проекте (About)
Данный проект разработан в рамках дисциплины **«Компьютерное зрение 1»**. Система решает задачу автоматизированной сортировки сельскохозяйственной продукции: распознает вид плода (из 11+ категорий) и определяет стадию его зрелости (**Ripe** / **Unripe**).

В отличие от тяжелых нейросетей (Deep Learning), проект построен на базе **классических алгоритмов компьютерного зрения (Classic CV)** и гибридного ансамбля **Random Forest**, что обеспечивает высокую скорость работы, полную интерпретируемость каждого этапа и независимость от мощных графических ускорителей (GPU).

---

## 🔬 Пайплайн обработки изображений (CV Pipeline)

Обработка каждого кадра проходит через 6 последовательных этапов:
1. **Предобработка и фильтрация:** Ресайзинг и подавление высокочастотных шумов матрицы с помощью **фильтра Гаусса** (`cv2.GaussianBlur`).
2. **Цветовое преобразовывание:** Перевод из пространства RGB в **HSV** для изоляции канала оттенка (`Hue`) от световых помех и теней.
3. **Сегментация и морфология:** Пороговая фильтрация по каналу насыщенности (`Saturation`) для точного отделения объекта от фона с последующим закрытием дыр морфологическими операциями.
4. **Контурный анализ и геометрия:** Поиск внешних границ (`cv2.findContours`) с расчетом масштаб-независимых признаков: округлости (*Circularity*), пропорций (*Aspect Ratio*), сплошности (*Solidity*) и инвариантных моментов Ху (*Hu Moments*).
5. **Гистограммный анализ:** Расчет нормализованных распределений цветов (H, S, V) непосредственно внутри маски объекта.
6. **Конкатенация признаков и классификация:** Объединение формы и цвета в единый вектор признаков, который передается классификатору **Random Forest** для итогового вердикта.

## 🛠 Технологический стек (Tech Stack)
* **Язык:** Python 3.10+
* **Компьютерное зрение:** OpenCV (`cv2`), NumPy
* **Машинное обучение:** Scikit-learn (Random Forest, Metrics, Train/Test Split)
* **Веб-интерфейс:** Streamlit, Matplotlib (для визуализации пайплайна в реальном времени)
